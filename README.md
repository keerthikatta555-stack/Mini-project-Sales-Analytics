# Global Electronics – Sales Analytics Project

## Project Overview

This project focuses on analysing sales performance for a retail business using the Global Electronics dataset. The objective is to transform raw sales data into meaningful business insights through data cleaning, data modelling, DAX calculations, and interactive Power BI dashboards.

## Tools Used

* Microsoft Excel – Initial data inspection and preparation
* Power Query – Data cleaning and transformation
* Microsoft Power BI – Data modelling, DAX calculations, and dashboard development

## Project Files

This folder contains the following files:

1. Project Documentation – Explains the project overview, problem statement, data cleaning, data modelling, DAX measures, dashboard development, testing, business insights, and conclusion.
2. Excel Dataset – Contains the dataset used for the sales analysis.
3. Power BI Report (.pbix) – Contains the interactive dashboards and visual analysis.

## Dashboard Pages

The Power BI report contains four pages:

1. Sales Overview

* Total Revenue
* Total Cost
* Total Profit
* Total Quantity
* Total Orders
* Profit Margin
* Monthly Revenue Trend
* Revenue by Category

2. Detailed Analysis

* Profit by Category
* Top 10 Products by Revenue
* Revenue by Country
* Revenue by Brand
* Country slicer for interactive filtering

3. Category Detailed

* Revenue, Profit, and Quantity KPIs
* Top 10 Products by Revenue
* Revenue by Brand

4. Customer & Store Analysis

* Customer Count
* Total Stores
* Average Revenue per Customer
* Revenue by Country
* Customer Count by Country

Project Workflow

1. Collected and explored the Global Electronics dataset.
2. Performed initial data inspection using Excel.
3. Cleaned and transformed data using Power Query.
4. Created fact and dimension tables.
5. Established relationships between tables in Power BI.
6. Created DAX measures for business calculations.
7. Developed four interactive dashboard pages.
8. Tested dashboard visuals, calculations, and slicer interactions.
9. Documented the project findings and business insights.

Key Learnings

* Data cleaning and transformation
* Power Query operations
* Data modelling and relationships
* DAX measures and calculations
* Interactive dashboard development
* Analysing sales and customer performance
* Communicating business insights through data visualisation

# Conclusion

This project provided hands-on experience in using Excel, Power Query, and Power BI to analyse retail sales data and convert raw data into meaningful business insights.
